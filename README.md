# Reseplanerare

## Beskrivning
En enkel webbapplikation för att planera resor genom att lägga till aktiviteter.

## Installation
1. Klona repo: `git clone <repo-url>`
2. Navigera till mappen: `cd reseplanerare`
3. Installera beroenden: `npm install`
4. Starta applikationen: `npm start`

## Användning
Fyll i formuläret för att lägga till aktiviteter och se dem listas nedan.
